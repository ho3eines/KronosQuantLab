# Kronos Quant Lab

سامانه محلی پژوهشی برای ارزیابی مدل‌های پیش‌بینی Kronos-small و Kronos-base روی داده روزانه رمزارز.

> **فقط پژوهش.** این پروژه به هیچ حساب واقعی وصل نمی‌شود، کلید API نمی‌گیرد و سفارش ارسال نمی‌کند. هیچ پیش‌بینی‌ای تضمین رفتار بازار نیست.

## وضعیت

مرحله **P0** (امکان‌سنجی و مقایسه دو مدل) — در مرحله شناسایی و طرح. هنوز هیچ مدلی دانلود یا اجرا نشده است.

| سند | محتوا |
|---|---|
| [docs/P0_plan.md](docs/P0_plan.md) | تحقیق منبع مدل، API واقعی، وابستگی‌ها، ریسک‌ها، طرح اجرا |
| [docs/P0_environment_report.md](docs/P0_environment_report.md) | گزارش محیط |
| [docs/DECISIONS.md](docs/DECISIONS.md) | تصمیم‌های فنی |
| [CHANGELOG.md](CHANGELOG.md) | تغییرات |

## تنها فرمان قابل اجرا در حال حاضر

بدون نصب، بدون تغییر در سیستم؛ فقط به Python نیاز دارد:

```powershell
py scripts\p0_env_probe.py
```

خروجی در `artifacts/reports/` ذخیره می‌شود. دستور نصب و اجرا پس از تأیید طرح P0 به این فایل اضافه می‌شود.
